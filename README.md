## 🗺️ 精選地圖：Stromguarde - Rifel Fast 系列

基於經典 6 人對戰地圖 **Stromguarde**，針對**人類步槍兵（Rifleman）**進行數值特化與專屬 AI 深度重構。

### ⚙️ 步槍兵數值調整
| 屬性項目 | 原版數值 | 特化數值 | 說明 |
| :--- | :--- | :--- | :--- |
| **基礎防禦力** | 0 | **3** | 生存率大幅提升 |
| **攻擊距離** | 400 | **1000** | 初始超遠距離打擊 |
| **主動索敵範圍** | 600 | **1150** | 配合射程主動接敵 |
| **攻擊間隔 (攻速)** | 1.35 秒 | **0.3 秒** | 極速連續射擊 |
| **攻擊前搖** | 0.17 秒 | **0.05 秒** | 出手極為迅速 |
| **攻擊後搖** | 0.56 秒 | **0.10 秒** | 射擊後硬直極低 |
| **子彈飛行速度** | 1900 | **3000** | 彈道飛行更快 |
| **長步槍科技** | 需 2 本主堡 | **僅需 1 本鐵匠鋪** | 一本即可升級，射程再 +300（達 1300），攻速再 +20% |

## 🤖 專屬人類 AI 進攻策略（`human.ai`）

1. **速步槍兵開局**：減少前期步兵護航（僅 2 隻步兵），提早建造鐵匠鋪並快速架設雙兵營。
2. **科技直升**：只要有鐵匠鋪即刻研發「長步槍」與遠程攻防升級。
3. **主動進攻推進**：
   * 1 英雄搭配 3 隻步槍兵即開始主動出門練級與推進。
   * 擁有 8 隻以上步槍兵時，解鎖 24 小時全天候攻城判定，不再受夜晚白天限制。
   * 防卡兵機制：人口即時動態補充，且成軍後英雄陣亡復活期間部隊不再在家原地發呆。

## 📦 安裝與遊玩方式

1. 下載 `maps/` 資料夾中的 `.w3x` 檔案。
2. 將檔案放置到本機魔獸爭霸3地圖目錄：
   * `文件\Warcraft III\Maps\` 或遊戲安裝路徑下的 `Maps\` 資料夾。
3. 進入遊戲開局，設定人類電腦玩家即可體驗特化 AI 對戰。
